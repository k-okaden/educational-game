# クラウド保存の設定（Firebase）

あそびのひろば は、だれでも無料で遊べます。ふだんは **ゲスト**（遊んだ記録はその端末の中だけ）で使えます。

記録をクラウドに保存して **2台目以降の端末と同期** したい場合は、各家庭で **自分の Firebase**（Google の無料サービス）を用意します。
データは自分の Firebase にだけ保存され、ほかの家庭やこのサイトの作者には送られません。

## 費用

- 無料の **Spark プラン** で足ります（クレジットカード登録不要）
- 無料枠を超えても請求はされず、その日は同期が止まるだけです
- 有料の Blaze プランに自分で切り替えない限り、課金されません

## 保存されるもの

| 場所 | 中身 |
|---|---|
| `users/{アカウント}` | こどもの なまえ・マーク・色、消したこども、ほしをリセットした時刻 |
| `users/{アカウント}/devices/{端末ID}` | その端末で遊んだ ほしの数・ゲームの進み具合 |

端末IDはランダムな文字列です。メールアドレスは Firebase のログインにだけ使います。

## 1. Firebase の準備（はじめに1回・15分くらい）

1. https://console.firebase.google.com を開き **プロジェクトを作成**
   - 名前は何でもOK（例：asobi-hiroba）
   - Google アナリティクスは **オフ**
2. **構築 → Authentication → 始める**
   - 「ログイン方法」→ **メール / パスワード** を有効にして保存（「メールリンク」はオフのまま）
3. Authentication の **ユーザー** タブ → **ユーザーを追加**
   - 保護者のメールアドレスとパスワードを入れる（このアカウント1つだけを使います）
4. Authentication の **設定** タブ → **ユーザーアクション**
   - **「作成（登録）を有効にする」のチェックを外す** ← ほかの人がアカウントを作れないようにする
   - 「削除を有効にする」も外す
5. **構築 → Firestore Database → データベースを作成**
   - ロケーション：`asia-northeast1`（東京）
   - **本番環境モード** で開始
6. Firestore の **ルール** タブに、このリポジトリの [`firestore.rules`](../firestore.rules) の中身を全部貼りつけて **公開**
7. ⚙️ **プロジェクトの設定** → 「マイアプリ」→ **ウェブ（`</>`）** でアプリを登録（Hosting は不要）
   - 表示される `const firebaseConfig = { ... };` を **まるごとコピー** しておく
8. （おすすめ）APIキーを このサイトだけで使えるようにする
   - https://console.cloud.google.com/apis/credentials → 同じプロジェクト → 「Browser key (auto created by Firebase)」
   - **アプリケーションの制限：ウェブサイト** → `https://k-okaden.github.io/*` を追加して保存

> apiKey などの firebaseConfig の値は、ブラウザに渡す前提の値でパスワードではありません。
> ただ、このアプリでは公開リポジトリには書かず、各端末にだけ保存します。

## 2. 1台目をログインさせる

iPad / iPhone は、**先に「ホーム画面に追加」してから、ホーム画面のアプリでログイン** してください（Safari とホーム画面のアプリは保存場所が別です）。

1. アプリを開く → **ログイン** → 「はじめての たんまつ：Firebase を せっていする」
2. コピーした firebaseConfig を貼りつけ、手順 1-3 のメールアドレスとパスワードを入れて **ログイン**
3. 「だれが あそぶ？」で こども を作る（双子なら2人）

## 3. 2台目以降をつなぐ（QR を読むだけ）

1. 1台目：⚙️ を **3秒長押し**（おとなメニュー）→ ☁️ クラウド → **2だいめを つなぐ** → QR が出る
2. 2台目：アプリを開く → **ログイン** → **QRを よみとる** → 1台目の QR をうつす
3. 自動でログインして、こども・ほしが同期されます

### QR の取りあつかい

- QR には ログイン情報が入っています。**家のカギと同じ** なので、ほかの人に見せないでください
- 端末をなくしたときなどは、おとなメニューの **「QRを つくりなおす」**
  - ログイン用のパスワードがランダムなものに変わり、古い QR と ほかの端末のログインは使えなくなります
  - ほかの端末は、新しい QR を読みなおしてください
  - 作りなおした後は、手順 1-3 で決めたパスワードも使えなくなります。全部の端末をなくしたときは、Firebase コンソールの Authentication → ユーザー で パスワードを再設定してください

## 4. 同期のタイミング

- ほしが増えたとき・ゲームの進み具合が変わったとき（数秒後）
- アプリを開いたとき・ネットにつながったとき
- おとなメニューの「いま どうき」

2台で同時に遊んでも、端末ごとに記録して合計するので、ほしが消えたり重なったりしません。

## 5. 消す（デバッグ用・おとなメニュー → 🛠 デバッグ）

| ボタン | 消えるもの | 残るもの |
|---|---|---|
| ほし0（こどもごと）／ほしを ぜんいん 0に | ほし | こども・進み具合・ログイン |
| こどもの「けす」 | そのこどもの ほし・進み具合（クラウド含む） | ほかのこども |
| この たんまつの データを ぜんぶ けす | この端末の保存すべて → 最初の画面へ | クラウドのデータ |
| クラウドの データを ぜんぶ けす | 自分の Firebase のデータすべて（全端末） | Firebase の設定・アカウント・ログイン |
| ぜんぶ リセット | 上の2つ → 最初の画面へ | Firebase のプロジェクト・アカウント |

消す前に2回確認します（2回目は「けす」と入力）。

## ゲームを増やしたとき

Firebase 側の作業は **ありません**。ルールは「本人のデータの下なら何でも可」の1本だけで、ゲームごとのデータは自動で保存されます。
