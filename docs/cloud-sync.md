# クラウド保存の設定（Firebase）

あそびのひろば は、だれでも無料で遊べます。ふだんは **ゲスト**（遊んだ記録はその端末の中だけ）で使えます。

記録をクラウドに保存して **2台目以降の端末と同期** したい場合は、各家庭で **自分の Firebase**（Google の無料サービス）を用意します。
データは自分の Firebase にだけ保存され、ほかの家庭やこのサイトの作者には送られません。

## 費用

- 無料の **Spark プラン** で足ります（クレジットカード登録不要）
- 無料枠を超えても請求はされず、その日は同期が止まるだけです
- 有料の Blaze プランに自分で切り替えない限り、課金されません

## しくみ

- ログインは Firebase の **匿名ログイン**。メールアドレスやパスワードは使いません
- データは「**おうち**」ごとにまとまります。おうちには ランダムな **合言葉** があり、合言葉（QR）を持っている端末だけが参加できます
- 参加していない端末は、おうちのデータを読むことも書くこともできません（[`firestore.rules`](../firestore.rules)）

| 場所 | 中身 |
|---|---|
| `households/{おうちID}` | 合言葉、参加している端末（名前）、こどもの なまえ・マーク・色、消したこども、ほしをリセットした時刻 |
| `households/{おうちID}/devices/{端末ID}` | その端末で遊んだ ほしの数・ゲームの進み具合 |

おうちID・端末ID・合言葉はランダムな文字列です。

## 1. Firebase の準備（はじめに1回・10分くらい）

1. https://console.firebase.google.com を開き **プロジェクトを作成**
   - 名前は何でもOK（例：asobi-hiroba）
   - Google アナリティクスは **オフ**
2. **構築 → Authentication → 始める**
   - 「ログイン方法」→ **匿名** を有効にして保存
   - ユーザーを作る必要はありません
3. **構築 → Firestore Database → データベースを作成**
   - ロケーション：`asia-northeast1`（東京）
   - **本番環境モード** で開始
4. Firestore の **ルール** タブに、このリポジトリの [`firestore.rules`](../firestore.rules) の中身を全部貼りつけて **公開**
5. ⚙️ **プロジェクトの設定** → 「マイアプリ」→ **ウェブ（`</>`）** でアプリを登録（Hosting は不要）
   - 表示される `const firebaseConfig = { ... };` を **まるごとコピー** しておく
6. （おすすめ）APIキーを このサイトだけで使えるようにする
   - https://console.cloud.google.com/apis/credentials → 同じプロジェクト → 「Browser key (auto created by Firebase)」
   - **アプリケーションの制限：ウェブサイト** → `https://k-okaden.github.io/*` を追加して保存

> **注意**：匿名ログインでは、Firebase の「新規登録をオフ」にはできません（オフにすると匿名ログインもできなくなります）。
> そのため firebaseConfig が他人に知られると、あなたの Firebase に別の「おうち」を作られて無料枠を使われる可能性があります（あなたのデータは合言葉がないと読めません）。
> このアプリは firebaseConfig を公開リポジトリには書かず、各端末にだけ保存します。手順 6 の制限もしておくと安心です。

## 2. 1台目：おうちを作る

iPad / iPhone は、**先に「ホーム画面に追加」してから、ホーム画面のアプリで操作** してください（Safari とホーム画面のアプリは保存場所が別です）。

1. アプリを開く → **ログイン** → 「はじめての たんまつ：Firebase を せっていして おうちを つくる」
2. コピーした firebaseConfig を貼りつけて **おうちを つくる**
3. QR が表示されるので、**印刷するかスクリーンショットで保存** しておく（2台目用・復旧用）
4. 「だれが あそぶ？」で こども を作る（双子なら2人）

## 3. 2台目以降をつなぐ（QR を読むだけ）

1. 1台目：⚙️ を **3秒長押し**（おとなメニュー）→ ☁️ クラウド → **2だいめを つなぐ** → QR が出る（保存した QR の画像でもOK）
2. 2台目：アプリを開く → **ログイン** → **QRを よみとる** → QR をうつす
3. 自動でおうちに入り、こども・ほしが同期されます

### QR の取りあつかい

- QR は **家のカギと同じ** です。ほかの人に見せないでください
- **すべての端末をなくしたとき** も、保存しておいた QR を読めば元に戻せます
- QR が他人に知られたときは、おとなメニューの **「QRを つくりなおす」**（合言葉が変わり、古い QR では入れなくなります。つながっている端末はそのまま）
- 端末をなくした・人にゆずったときは、おとなメニューの「つながっている たんまつ」で **はずす**
  - 外した端末で遊んだ ほし は残ります
  - 外された端末は、記録をゲストとして端末に残して ゲストにもどります

## 4. 同期のタイミング

- ほしが増えたとき・ゲームの進み具合が変わったとき（数秒後）
- アプリを開いたとき・ネットにつながったとき
- おとなメニューの「いま どうき」

2台で同時に遊んでも、端末ごとに記録して合計するので、ほしが消えたり重なったりしません。

## 5. 消す（デバッグ用・おとなメニュー → 🛠 デバッグ）

| ボタン | 消えるもの | 残るもの |
|---|---|---|
| ほし0（こどもごと）／ほしを ぜんいん 0に | ほし | こども・進み具合・ログイン |
| こどもの「けす」 | そのこどもの ほし・進み具合（クラウド含む） | ほかのこども |
| この たんまつの データを ぜんぶ けす | この端末の保存すべて（おうちからも抜ける）→ 最初の画面へ | クラウドのデータ |
| クラウドの データを ぜんぶ けす | おうちの こども・ほし・進み具合（全端末） | おうち・つながっている端末・QR |
| ぜんぶ リセット | 上の2つ → 最初の画面へ | Firebase のプロジェクト・おうち |

消す前に2回確認します（2回目は「けす」と入力）。

## ゲームを増やしたとき

Firebase 側の作業は **ありません**。ルールには ゲームごとの項目を書いていないので、ゲームのデータは自動で保存されます。
